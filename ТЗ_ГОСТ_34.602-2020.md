# Техническое задание на создание автоматизированной системы
(Составлено в соответствии с ГОСТ 34.602-2020)

## 1. Общие сведения
- **Наименование АС:** Программный комплекс для вычисления специальных числовых последовательностей.
- **Заказчик:** Учебное заведение (лабораторная работа).
- **Разработчик:** Студент.

## 2. Цели и назначение создания АС
- **Цель:** Автоматизация процесса вычисления чисел Фибоначчи и треугольных чисел.
- **Назначение:** Выполнение расчетов в рамках учебного процесса и демонстрация навыков разработки ПО.

## 3. Требования к автоматизированной системе
- **Требования к структуре АС в целом:** Система должна состоять из исполняемого файла (CLI) и подключаемого модуля вычислений.
- **Требования к функциям:**
  - Вычисление n-го числа Фибоначчи.
  - Вычисление n-го треугольного числа.
  - Обработка ввода пользователя через консоль.
- **Общие технические требования:** Язык реализации — Python 3. Система должна корректно обрабатывать целочисленные значения.

## 4. Порядок контроля и приемки
- Проверка корректности вычислений для эталонных значений (например, F(10)=55, T(10)=55).
