# Спецификация требований к программному обеспечению (SRS)
(Составлено в соответствии с ISO/IEEE 29148-2011)

## 1. Введение
- **Цели:** Определить функциональные и нефункциональные требования к программе вычисления числовых последовательностей.
- **Область применения:** Программа предназначена для использования в командной строке.

## 2. Общее описание
- **Функциональность продукта:**
  1. Прием аргументов командной строки (номер члена последовательности и тип вычисления).
  2. Вызов соответствующей функции из модуля.
  3. Вывод результата в stdout.
- **Классы пользователей:** Студент / Преподаватель.
- **Среда функционирования:** Кроссплатформенная ОС (Windows/Linux/macOS), интерпретатор Python 3.6+.

## 3. Функциональные требования
- **FR-01:** Система должна вычислять число Фибоначчи по формуле F(n) = F(n-1) + F(n-2).
- **FR-02:** Система должна вычислять треугольное число по формуле T(n) = n*(n+1)/2.
- **FR-03:** Система должна принимать на вход целое неотрицательное число n.

## 4. Нефункциональные требования
- **NFR-01 (Производительность):** Время вычисления для n <= 1000 не должно превышать 1 секунды.
- **NFR-02 (Надежность):** При некорректном вводе (например, отрицательное число или текст) программа должна выводить сообщение об ошибке и завершаться с ненулевым кодом.
