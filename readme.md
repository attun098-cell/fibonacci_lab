# Лабораторная работа: Вычисление чисел Фибоначчи и фигурных чисел

## Описание задачи
Программа на языке Python вычисляет n-е число Фибоначчи и n-е треугольное фигурное число.

## План разработки
1. Изучение Git и создание репозитория.
2. Написание технического задания (ГОСТ 34.602-2020).
3. Написание спецификации требований (ISO/IEEE 29148-2011).
4. Реализация модуля вычислений.
5. Реализация интерфейса командной строки.
6. Тестирование и фиксация в Git.
